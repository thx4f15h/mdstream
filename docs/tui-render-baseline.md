## 验收口径

### TUI：固定 cell 网格等价

- 比较对象是终端尺寸和正文内容区固定后的 cell 网格，不比较原始 ANSI 字节流。等价范围至少包括：可见字符、宽字符占位、样式角色、前景/背景、链接范围、块间距、折行后的行数和列位置。
- cell 网格中的行由坐标表达，不以 CRLF 结束，也不输出行尾 CRLF。交互帧使用 CSI 光标寻址和 cell diff；正常帧不清屏、不无条件归位，首帧、resize 和终端恢复才允许清屏/归位。
- 标题、代码块、表格等不折行块在进入网格前按正文内容区宽裁剪，禁止把越界 cell 交给终端自动折行。无侧栏时 `content_width == term_w`；有侧栏时 `content_width == term_w - sidebar_width`，因此侧栏开关会改变裁剪宽度。
- 段落、列表和引用按参考规则折行，不以终端自动折行补足；宽字符只占首 cell，后续 cell 标记为占位。
- 空文档在交互模式下仍是终端生命周期内的空白网格，不等同于 `--once` 的零字节输出。

### `--once`：逐语义段字节精确

- `--once` 是唯一要求原始 ANSI 字节与参考输出对齐的模式；以语义段为比较单位，逐段核对字符、转义序列、复位、OSC 8 和换行字节。
- 保留参考 §0 的 CRLF 行尾，包括文档最后一行和空行；表格内部行之间保留单个 LF；纯空白或空输入输出零字节；全屏输出按参考 §0/P61 使用 `ESC[2J ESC[H` 前缀。
- 样式序列按参考 §2 自包含：开序列 + 文本 + `ESC[0m`，按粗体、斜体、下划线、删除线、前景、背景的固定顺序发射；不得用 `ESC[39m`/`ESC[49m` 代替复位。
- 超宽标题、代码块和表格不裁剪，保留参考行字节；终端可能自动折行，但原始 golden 只比较发送的字节，不把终端自动折行后的屏幕当作 `--once` 字节 oracle。
- 不得复制参考实现的 HTML 块崩溃。HTML 输入在两种模式下都必须安全处理；其具体安全跳过/原文策略由后续 P16/P62 定案，未定案前不把参考的“崩溃、无输出”当作可通过的字节 golden。

### 模式关系

- TUI cell 网格 oracle 与 `--once` 原始字节 oracle 是两套验收，不允许用 TUI 截图替代 `--once` golden，也不允许用 `--once` 的 CRLF/溢出字节直接断言 TUI 行寻址。
- 对没有 HTML 崩溃和超宽不折行块的 fixture，可把 `--once` 字节在固定终端中解码为 cell 网格，再与 TUI 网格比较；对超宽块只比较内容区内的可见前缀，并单独记录 `--once` 溢出和终端自动折行风险。

## 必须冻结的差异

1. **行尾与帧寻址**：TUI 使用固定 cell 网格，不做行尾 CRLF；交互帧用光标寻址和 diff，正常帧不清屏。`--once` 才保留参考 CRLF、表格内部 LF 和全屏清屏字节。
2. **字节精确范围**：只有 `--once` 做逐语义段原始 ANSI 核对；TUI 只保证固定内容区宽下的 cell 等价，不保证相同转义序列切分、复位次数或输出字节。
3. **超宽不折行块**：TUI 对标题、代码块和表格等按正文内容区宽裁剪；无侧栏时等于终端宽，侧栏开关改变宽度并重排/失效宽度相关缓存。`--once` 保留完整参考字节，可能发生终端自动折行。
4. **HTML 安全策略（P16 已冻结）**：不复制参考实现的崩溃行为。行内标签、属性、自闭合标签、声明和注释在可见 token 内被移除，标签间文字保留；若当前段落以可识别的 HTML block 起始标记（注释、声明、CDATA、处理指令或常见块级标签）开始，则整个当前块安全跳过，后续空行分隔的段落照常渲染。`Definition` / `FootnoteDefinition` 整块跳过。`--once` 后续复用同一可见性策略，HTML 崩溃不作 golden。
5. **嵌套强调与 MATH 固定优先级（P14 已冻结）**：核心 `Style` 是位并集，无法恢复参考要求的“外层决定前景”。TUI 固定采用 `CODE > MATH > STRONG/EMPHASIS > STRIKE`；`LINK` 是独立链接色层，在非 CODE 组合中保留 P15 前的链接色，不被 `MATH` 默认前景或 `STRONG`/`EMPHASIS`/`STRIKE` 覆盖。MATH 没有参考颜色，选终端默认前景且无背景，但保留粗体/斜体/删除线属性。因此 `**a ~~b~~**` 与 `~~a **b**~~` 的 `b` 都解析为 `STRONG|STRIKE`，字节同为粗体 + 删除线 + 强调色；外层删除线本应决定前景的参考行为不可恢复。`**$x$**` 实际为 `ESC[1m` + `x` + `ESC[0m`，不再发射强调粉色。P62 记录该差异并保留 fixture。
6. **后续差异预留**：表格渐进宽度（P36）、流式期间链接延迟到 EOF 解析及 destination 解码（P55）、终端 truecolor/OSC 8 能力差异（P60/P62）均在此登记，待对应任务实现时补 fixture 和验收证据，不在 P00 声称已完成。

### P14 内联样式裁定（2026-10-31）

| 输入/组合 | TUI 解析结果 | 与参考规格的关系 |
| --- | --- | --- |
| `**a ~~b~~**`、`~~a **b**~~` | `b` 均为 `STRONG|STRIKE`，均使用 `#FF79C6` 前景 + 粗体 + 删除线 | 无法区分外层；外删内强的参考“外层决定前景”不可恢复，两者字节刻意相同 |
| `**$x$**` | `x` 为 `STRONG|MATH`；保留粗体，前景回到终端默认、无背景 | 参考规格无 MATH 视觉；不让强调粉色覆盖数学默认前景 |
| `MATH` | 裸文本，无 SGR | 与参考把内联数学当普通文本的可见结果一致 |
| `CODE + STRONG/EMPHASIS/STRIKE` | 代码前景 `#A6E22E` + 背景 `#282828`，保留粗体/斜体/删除线 | CODE 前景优先；属性顺序仍为粗体→斜体→删除线→前景→背景 |
| `LINK + STRONG/EMPHASIS/STRIKE`（非 CODE） | 链接前景 `#8BE9FD` + 单下划线，保留强调/删除线属性 | 链接色不被强调/删除线或 MATH 默认前景覆盖；OSC 8 仍留到 P15 |

所有 styled segment 仍为自包含 `start + text + ESC[0m`；相邻段独立复位，不使用 `ESC[39m`/`ESC[49m`。

### P16 HTML 与不可见内容策略（2026-10-31）

- **图片（当前合同覆盖 P16）**：保留显示 alt 和 LinkId，空 alt 为 `[image]`；标题、列表和表格也保留图片对象，目标受输出预算。旧参考的删除策略已经撤销。
- **脚注**：通过 `footnote_references_in` 与 `resolve_footnote` 按 `FootnoteReference.source` 删除已定义引用；`Missing`/`Unresolved` 引用继续显示原文。`FootnoteDefinition` 整块不进入可见渲染。`Definition` 链接/引用定义块同样整块跳过；P10 已跳过其 HIDDEN display runs。
- **行内 HTML**：当前块的映射安全文本 token 中，删除标签、属性、自闭合标签、声明和注释；被标签包围的普通文字保留。注释内容整体不显示；未闭合的普通标签保留原文，未闭合注释/声明只清理到当前 token 末尾，均不 panic。代码 token 与实体替换 token 不参与标签扫描，避免误删代码或 `&lt;` 解码后的文本。
- **HTML block**：核心没有独立 HTML block 类型，因此在当前段落首可见文本上做启发式识别。以 `<!--`、`<![CDATA[`、`<?`、大小写不敏感的 `<!doctype`，或常见块级标签（含 `div`、`table`、`pre`、`script`、`style` 等）起始时，整个当前块返回 0 行；不复制参考崩溃。后续由空行分隔的正常段落不受影响。
- **限制**：该识别不是完整 CommonMark HTML block 状态机；块内出现空行、未知自定义块标签或标签跨 display token 边界时，可能按普通段落及行内清理处理。P62 必须以此启发式边界核对 HTML fixture，不能声称完整 HTML 兼容。

## 计划与参考规格的已知口径张力

- 参考 §3.3 要求嵌套强调由最外层决定前景，而计划 §4.1/P14 已确认核心 `Style` 只有位并集，无法恢复嵌套顺序。P14 已把固定优先级和 MATH 选择落实为明确的可测试裁定；因此 `--once` 不能对所有嵌套强调 fixture 声称与参考逐字节全等，相关 golden 必须按 P14/P62 的已记录差异解释，不能静默放宽整个 `--once` oracle。
- 参考 §8 是 ratatui 后端的差异说明，而计划要求 TUI 支持外链显示、引用目标及 H1–H5 下划线变体。二者并非同一后端契约；本文只把 §8 当作需要显式确认的后端风险，不把它当作 TUI 的默认降级授权。

本文记录旧参考的视觉基线；当前实现、已更新 oracle 和未完成范围见终端集成说明，不以旧实验阶段状态代替当前验收。
