## 验收口径

### TUI：固定 cell 网格等价

- 比较对象是终端尺寸和正文内容区固定后的 cell 网格，不比较原始 ANSI 字节流。等价范围至少包括：可见字符、宽字符占位、样式角色、前景/背景、链接范围、块间距、折行后的行数和列位置。
- cell 网格中的行由坐标表达，不以 CRLF 结束，也不输出行尾 CRLF。交互帧使用 CSI 光标寻址和 cell diff；正常帧不清屏、不无条件归位，首帧、resize 和终端恢复才允许清屏/归位。
- 标题、代码块、表格等不折行块在进入网格前按正文内容区宽裁剪，禁止把越界 cell 交给终端自动折行。无侧栏时 `content_width == term_w`；有侧栏时 `content_width == term_w - sidebar_width`，因此侧栏开关会改变裁剪宽度。
- 段落、列表和引用按参考规则折行，不以终端自动折行补足；宽字符只占首 cell，后续 cell 标记为占位。
- 空文档在交互模式下仍是终端生命周期内的空白网格，不等同于 `--once` 的零字节输出。

### `--once`：逐语义段字节精确

- `--once` 是唯一要求原始 ANSI 字节与参考输出对齐的模式；以语义段为比较单位，逐段核对字符、转义序列、复位、OSC 8 和换行字节。
- 保留参考 §0 的 CRLF 行尾，包括文档最后一行和空行；表格内部行之间保留单个 LF；纯空白或空输入输出零字节；全屏输出按参考 §0/P61 使用 `ESC[2J ESC[H` 前缀。
- 样式序列按参考 §2 自包含：开序列 + 文本 + `ESC[0m`，按粗体、斜体、下划线、删除线、前景、背景的固定顺序发射；不得用 `ESC[39m`/`ESC[49m` 代替复位。
- 超宽标题、代码块和表格不裁剪，保留参考行字节；终端可能自动折行，但原始 golden 只比较发送的字节，不把终端自动折行后的屏幕当作 `--once` 字节 oracle。
- 不得复制参考实现的 HTML 块崩溃。HTML 输入在两种模式下都必须安全处理；其具体安全跳过/原文策略由后续 P16/P62 定案，未定案前不把参考的“崩溃、无输出”当作可通过的字节 golden。

### 模式关系

- TUI cell 网格 oracle 与 `--once` 原始字节 oracle 是两套验收，不允许用 TUI 截图替代 `--once` golden，也不允许用 `--once` 的 CRLF/溢出字节直接断言 TUI 行寻址。
- 对没有 HTML 崩溃和超宽不折行块的 fixture，可把 `--once` 字节在固定终端中解码为 cell 网格，再与 TUI 网格比较；对超宽块只比较内容区内的可见前缀，并单独记录 `--once` 溢出和终端自动折行风险。

## 必须冻结的差异

1. **行尾与帧寻址**：TUI 使用固定 cell 网格，不做行尾 CRLF；交互帧用光标寻址和 diff，正常帧不清屏。`--once` 才保留参考 CRLF、表格内部 LF 和全屏清屏字节。
2. **字节精确范围**：只有 `--once` 做逐语义段原始 ANSI 核对；TUI 只保证固定内容区宽下的 cell 等价，不保证相同转义序列切分、复位次数或输出字节。
3. **超宽不折行块**：TUI 对标题、代码块和表格等按正文内容区宽裁剪；无侧栏时等于终端宽，侧栏开关改变宽度并重排/失效宽度相关缓存。`--once` 保留完整参考字节，可能发生终端自动折行。
4. **HTML 块**：不复制参考实现的崩溃行为。TUI 与 `--once` 都必须安全退出或安全处理；安全跳过/原文显示策略留给 P16/P62，当前只冻结“不得崩溃”和“不得以崩溃输出作为 golden”。
5. **嵌套强调**：核心 `Style` 是位并集，无法恢复参考要求的“外层决定前景”。后续按 P14 固定优先级 `CODE > MATH > STRONG/EMPHASIS > STRIKE`，P62 记录具体差异；这会使含嵌套强调的 fixture 无法同时满足参考字节全等和核心能力约束。
6. **后续差异预留**：表格渐进宽度（P36）、流式期间链接延迟到 EOF 解析及 destination 解码（P55）、终端 truecolor/OSC 8 能力差异（P60/P62）均在此登记，待对应任务实现时补 fixture 和验收证据，不在 P00 声称已完成。

## 计划与参考规格的已知口径张力

- 参考 §3.3 要求嵌套强调由最外层决定前景，而计划 §4.1/P14 已确认核心 `Style` 只有位并集，无法恢复嵌套顺序。计划给出的固定优先级是明确的可测试裁定，但因此 `--once` 不能对所有嵌套强调 fixture 声称与参考逐字节全等；相关 golden 必须按 P14/P62 的已记录差异解释，不能静默放宽整个 `--once` oracle。
- 参考 §8 是 ratatui 后端的差异说明，而计划要求 TUI 支持外链显示、引用目标及 H1–H5 下划线变体。二者并非同一后端契约；本文只把 §8 当作需要显式确认的后端风险，不把它当作 TUI 的默认降级授权。
